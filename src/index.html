Glossy

Select text anywhere and translate it on the spot.

Closing this window keeps Glossy in the notification area. The tray icon is the only way back.

Features

Settings

Translate

Type or paste a text, then select a word, a phrase or a sentence — or press Translate — to see the result right here, in the same card as the popup.

Nothing selected yet.

Screenshot translation

Press the shortcut below, or the button, and the screen freezes; drag a rectangle over the text you want to read and it is translated in the usual popup. Escape, a right click or a rectangle that selects nothing cancels.

The shortcut works in every program, without opening this window first.

Text recognition on this machine

The recognition engine and the other files Glossy needs are downloaded and removed on the Resources page.

Subtitles

Read a part of the screen again and again and draw its translation where you want it. Pick the language the subtitles are written in and the one you read them in, then pick two rectangles: the area the subtitles appear in, and the place the translation is to be drawn. Every time what is read changes, the translation follows. Nothing is uploaded: the picture is read on this machine and only the text goes to the translator.

What is read, and what it is translated into

Only this one language reads the region, which is what keeps a reading down to a fraction of a second; other languages can be checked on the Resources page for screenshots without slowing this down.

Reading

Both boxes wear a faint dashed frame while a reading runs. This opens them over the video to drag and resize — either the rectangle the subtitles are read from or the one the translation is drawn in — and the reading follows the boxes it is left with.

The window is drawn exactly where the second rectangle was picked and it lets every click through, so a subtitle is never in the way of the video. Come back to this page to stop the reading.

Document translation

Document translation is still being built. Nothing is translated yet and every request is refused until it is finished.

Document translation

Translate a whole file at once — a plain text file, a Markdown file, a subtitle file, a PDF or a Word document. Everything is translated in order and the result is saved where you choose. Nothing else changes: a heading stays a heading, code stays code, a subtitle keeps its timings, and a Word document keeps its styles, its tables and its pictures. A PDF is read into plain text, and a scanned one holds no text to read.

Plain text, Markdown, subtitles (.srt), PDF or Word (.docx)

Resources

            

              Everything Glossy needs to work without a connection is downloaded here
              and kept on this machine. Nothing is downloaded until you ask for it, and
              every file says where it comes from.
            


            

              

                

                  
Reading engine

                  

                    The runtime that runs the models and the detector that finds the
                    lines of text, whatever language they are in. Downloaded once, shared
                    by every language, about 21 MB.
                  

                

                

                  
                  
                

              

              

              

                

              

            


            

              

                

                  
Recognition languages

                  

                    Every language you check is read with: a screenshot is read with all of
                    them at once, and each line is kept from the language that read it best.
                    A language reads its own script and nothing else, so check the ones you
                    really meet.
                  

                

              

              
    
              
    
              
    
                Every language is an ONNX distribution of PaddleOCR's PP-OCR model by
                RapidOCR, licensed under Apache-2.0.
              
    
            
    

            
    
              
    
                
    
                  
    Offline translation
    
                  
    
                    Translating without a connection, by a model that runs here. Chinese and
                    English both ways, and nothing is sent anywhere — which is why this one
                    channel has no allowance to count. About 244 MB, downloaded once.
                  
    
                
    
                
    
                  
                  
                
    
              
    
              
    
              
      
              
      
                
      
              
      
              
      
                OPUS-MT's Chinese and English models (Helsinki-NLP, CC-BY-4.0), exported to ONNX
                and quantized to int8.

              Pronunciation uses the voices Windows already has; the language of a text picks the
              voice. A word is only looked up in its sentence when the program in front lets
              Glossy read it.
            
        
          
        
        
        
        
        
          
        
            
        Units
        
            
        
              
            
        
            
        
              A measurement or an amount of money that reads the way the source language writes it
              is shown again the way the target language writes it, with the conversion rate.
              Currency rates are looked up live.
