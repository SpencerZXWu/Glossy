## English

### Added

- The translate box that the settings window already carried now sits at the top
  of the window, above the enable switch, so the app can be used without
  selecting text anywhere: it gained **Paste** (reads the Windows clipboard
  through a new `read_clipboard` command), **Clear**, Ctrl+Enter to translate the
  whole text, and a pasted text is translated as soon as it lands. A new
  **Units** switch on the same heading turns unit conversion on and off from
  there — it is bound to the existing setting below, so either switch moves both
  and the visible card is redrawn with or without its conversions.

## 中文

### 新增

- 设置窗口本来就带的那个翻译框现在移到了窗口顶部、总开关的上方，因此不选中任何文本也能使用：它新增了**粘贴**（通过新的 `read_clipboard` 命令读取 Windows 剪贴板）、**清空**、用 Ctrl+Enter 翻译整段文本，粘贴进来的文本一落地就会翻译。同一行标题上的**单位换算**开关可以从这里开关整个应用的换算功能——它与下方原有的那个设置绑定，任一侧切换都会同步另一侧，并即时重绘当前卡片（带或不带换算结果）。

## Español

### Añadido

- El cuadro de traducción que ya traía la ventana de ajustes ahora está en la parte superior de la ventana, encima del interruptor principal, así que la aplicación se puede usar sin seleccionar texto en ninguna parte: ha ganado **Paste** (lee el portapapeles de Windows mediante el nuevo comando `read_clipboard`), **Clear**, Ctrl+Enter para traducir todo el texto, y un texto pegado se traduce en cuanto llega. Un nuevo interruptor **Units** en el mismo encabezado activa y desactiva la conversión de unidades para toda la aplicación: está enlazado con el ajuste que ya existía más abajo, de modo que cualquiera de los dos mueve al otro y la tarjeta visible se vuelve a dibujar con o sin sus conversiones.
